# Phase 4 — Guided multicolor
Phase 3B approved and merged (37 unit/integration tests, 18 Chrome checks, run 45693782623). Phase 4 focuses on an ordered sequence of selected source stroke colors. Mixed SVG groups are not treated as one color. Switch to stroke mode, choose colors, reorder and prepare a sequence. One ink is selected at a time using the existing planner and entire source artwork; placement, file and layer controls are locked until exit. Closing restores the original selection.

Dry run is explicitly motion-free, uses the real plan and requires a separate simulated-layer action and confirmation at every step. Live job preparation is restricted to validated Manual placement with confirmed measured machine travel and a connected physical device. Each ink requires its own explicit Plot click; completion does not trigger motion. Confirm the machine has stopped and check origin before continuing. WebSerial completion waits for the plot promise; Node checks /plot/status and rejects failed plot HTTP requests. Use a single controller/client; do not change origin or move the carriage between inks. Cancellation/disconnection interrupts the sequence; no automatic retry or resume.

No planner or motion algorithm changes. The only transport change makes SaxiDriver.plot report HTTP rejection. No pen-width overrides, sheet tint or persistent queue in this increment. Existing single-layer workflow remains available. Browser tests exercise dry run, ordering, locking, restoration and no hardware access; live physical operation remains unverified until Phase 5.
