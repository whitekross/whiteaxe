# Phase 3 — Manual placement

Implementation in review. Fit and Original still use upstream placement behavior; Manual anchors the rotated full artwork bounds to X/Y mm from the paper origin, at a percentage of physical SVG size. Entering Manual from Fit preserves fitted position and scale. Center X/Y/both use the full artwork. Drag previews a local draft and commits a single replan on release; numeric controls are the accessible alternative. No clipping in Manual; invalid or off-paper geometry and unconfirmed/out-of-range machine travel block planning. Upstream hardware definitions do not specify travel dimensions: user must enter measured usable X/Y from the physical machine origin each session (reset on hardware change). Paper must be aligned to that origin. This is a software guard, not calibration or a hardware test.

Original technical preview remains available. Plan readiness is tied to exact input paths and options; Plot is blocked while stale/dragging. Controls lock during reported plotting progress. No driver or motion algorithm changes. Tests added for placement, rotation, scale, stable selection, center, bounds and plan equivalence. CI/browser results pending.
